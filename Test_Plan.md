# Test Plan for Blockchain CRUD Application

## **1. Introduction**
This document outlines the test plan for verifying the blockchain node onboarding and private blockchain creation functionalities.

## **2. Test Scenarios**
### **A. Sign Up**
- ✅ **Valid Test Cases**: Sign up with valid email & password.
- ❌ **Invalid Test Cases**: Sign up with invalid email format, weak password, existing email, etc.

### **B. Sign In**
- ✅ **Valid Test Cases**: Login with correct credentials.
- ❌ **Invalid Test Cases**: Incorrect password, non-existent email, blank fields.

### **C. Sign Out**
- ✅ **Valid Test Cases**: Successfully log out.
- ❌ **Invalid Test Cases**: Trying to access restricted pages after logging out.

*More scenarios can be added for submitting requests to onboard nodes and create blockchains.*
